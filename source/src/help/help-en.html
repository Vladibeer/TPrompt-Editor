What is TPrompt

TPrompt is a teleprompter: it shows your text on screen and scrolls it at the speed you choose while you read. It works on its own, and also with a second window, a second display, or a phone or tablet connected over the network. Texts and settings are kept on this device and are never sent to the internet.

Quick start

  1. Type or paste your text in the editor, or open it from a file with the Open button above the Library. Formatting from Word, Google Docs and web pages is kept. In the Windows and Android apps a file (.docx, .odt, .rtf, .txt) on a local or network drive can be linked to the text: changes are saved back into it and external changes are watched (Settings → Sync linked file). Files from Google Drive, OneDrive and other cloud services open only as a copy: the cloud is not used for synchronization.
  2. Optionally split the text into parts: start a line with ~ and a title, for example ~News. This creates bookmarks for quick navigation to each part.
  3. Press Start and choose how to read: Full screen or In a window. Ctrl+Enter starts full screen right away.
  4. Space plays and pauses, ↑ and ↓ change the speed, and + and − change the letter size.
  5. Esc or E takes you back to the editor.

The main screen

  • The top bar has the Library, Editor and Bookmarks buttons, which show and hide the panels, the Start button and the Settings button, which opens a settings window. The Editor button is active only when a second window is open or a device is connected, because otherwise the editor is always visible. On a narrow screen (phone) only one panel is open at a time.
  • The formatting bar is above the text.
  • The left panel shows the Library (key T), and the right panel shows the Bookmarks of the shown text, or of the text in the editor when nothing is being shown (key B). The panels are shown and hidden independently with the buttons at the very top.
  • The editor is in the middle. Below it, “Saved” appears once your changes are written.
  • Settings open in a window with the Settings button at the top right (key S), and also while reading. At the bottom is the Help button (or press F1).

Editor

  • The bar has: undo and redo (Ctrl+Z, Ctrl+Y), paragraph style (Paragraph, Heading 1–3), font, size, bold (Ctrl+B), italic (Ctrl+I), underline (Ctrl+U), strikethrough (Ctrl+Shift+X), text color, highlight, alignment (left, center, right), bulleted list and numbered list.
  • The size in the bar is in points, as in Word, and applies to the selected text. The overall reading size is changed in Settings or with + and −.
  • The Add a bookmark to this line button adds or removes the ~ sign at the start of the line. The Clear formatting of selection button removes formatting from the selected text.
  • Pictures (.png, .jpg, .gif, .webp) are inserted with the Insert picture button. Click a picture and a frame appears with buttons for width 25, 50, 75 and 100%, for alignment and for deleting. You can also resize it by dragging the corner.
  • Spell checking is turned on in Settings.
  • Note (Ctrl+~) adds [brackets] and colors them so the reader can follow along: [pause], [applause]. With nothing selected it inserts [] with the cursor inside; with selected text it wraps it; on an existing note it removes it. The color of all notes is changed with the chevron next to it.
  • Everything you type is saved automatically.

Library

The Library button at the very top (key T) shows the list of your texts in the left panel. Each entry is a separate text, for example “News” and “Sports” in one broadcast.

  • Above the list there are three buttons: New text (it asks for a name; an empty name means the name is the first line), Open (opens a file) and Export.
  • Each row has a number, a name and two buttons: Edit text (✎) and Text actions (⋯). Clicking the name starts reading that text in the chosen way (full screen or in a window); with a second window open or a device connected it is shown there, while the editor stays on the current text. The Edit text button opens it for editing, and Text actions offers: Rename, Duplicate, Move up, Move down and Delete.
  • This way, with a second window, one text can be shown while another is being edited.
  • While reading, T shows the list of texts, and N and P switch to the next and previous one. When a text ends, the next one is shown.
  • Texts are kept on this device. Keep important copies with Export too.

Bookmarks

A line that starts with ~, for example ~First story, is a bookmark. The ~ sign is visible only in the editor. Bookmarks are shown in the right panel with the Bookmarks button at the very top (key B).

  • Clicking a bookmark's name starts reading from there. The Edit bookmark button (✎) goes to that line in the editor.
  • While reading, the digits 1–9 go to the bookmark with that number. For larger numbers press the digits one after another, for example 1 and 2 for bookmark 12. > and < go to the next and previous bookmark, and B shows the list.

Opening and saving

  • Open (the button above the Library, or Ctrl+O) adds a .docx, .odt, .rtf or .txt file to the list as a new text. You can also drop a file onto the window. The old .doc format is not readable: save it as .docx.
  • If the file is a list of texts from TPrompt (.json), the program asks whether to replace the current list or add to it.
  • Export (the button above the Library, or Ctrl+S): for this text it is DOCX (Word, Google Docs), ODT (LibreOffice, OnlyOffice), RTF (an older format for the same editors) or TXT (plain text). DOCX, ODT and RTF keep formatting and pictures. For all texts it is a single JSON file with bookmarks and settings. The file can also be saved to Google Drive, OneDrive, etc. through the system dialog, but that only saves a copy; it is not synchronization.
  • .docx files are read by a built-in reader. If it fails, the program tries a fallback that may need an internet connection.

Starting to read

The Start button begins reading in the chosen way. If the way is not remembered, a choice opens:

  • Full screen reads on this screen. Ctrl+Enter starts it right away.
  • In a window opens a separate reading window, for example on a second monitor (Shift+Enter).
  • Network (in Settings) connects a phone, tablet or another computer. The icon and the label next to it show the status: connected or no connection. Once connected, Start offers a button that shows the text on the other device.
  • “Remember my choice” saves the choice; it is changed later in Settings → Start mode. Shift+click on “Start” or Ctrl+Shift+Enter always show the choice.

Reading

  • A control bar at the bottom has: start over (Home), play and pause, a progress bar (clicking it moves to the chosen place), speed, size, marker, mirror, time and percent, Library, Bookmarks, Settings, Full screen and Back to the editor. It is shown and hidden with C or the Show or hide controls button; the arrow button is at the bottom centre. The second row of the panel has play/pause, Library, Bookmarks, Settings, Home, Rotate screen and Close. The list of texts and bookmarks opens on the right, and Settings opens in a window over the text.
  • Speed is from 1 to 100. ↑ and ↓ change it in steps of 5, or 1 with Shift. “Swap up and down” in Settings swaps the direction of the arrows.
  • Mouse: the wheel scrolls. A click in the middle plays and pauses. A double click at the top or bottom edge (18% of the height) changes the speed: top is slower, bottom is faster.
  • Touch screen: dragging scrolls. A tap in the middle plays and pauses. A double tap at the top or bottom edge changes the speed. Two fingers change the letter size.
  • Marker (M) underlines a reading line and dims the rest. [ and ] move it. Its position, height, dimming and color are in Settings.
  • Mirror is for a beam-splitter teleprompter: H flips horizontally, V vertically.
  • Full screen is toggled with F. When the text ends, scrolling stops by itself.

Second window or second display

  • Start → In a window (or Shift+Enter) opens a separate reading window. If there is a second display, “Open on the second screen” is written under the name and the window moves there.
  • In the new window, the first click or key press makes it full screen.
  • While it is open, a preview with buttons for play, start over, progress, speed and size is shown in place of the editor. The preview is a copy of the second window. The editor comes back with the Editor button.
  • Space, ←, →, Home, End and the digits control the second window after you click on the preview. Clicking elsewhere returns the keys to the editor.
  • Changes to the text are sent to the second window automatically.
  • To close it: Start → Close window, Shift+Enter, or the Close button in the preview and in the window itself.

Network: phone, tablet or presenter

  • The link works between any two devices: computer and phone, two phones, two computers. One shows a QR code and the other scans it. Open Settings, and in the Connection tab choose Monitor (shows a QR code) or Remote (scans a QR code). The choice is remembered. Once connected, the same button becomes Disconnect.
  • Monitor shows a QR code, an address and the status, with the buttons New code (makes the old address invalid), Copy and Disconnect. Remote scans the code with the camera (a computer uses its webcam) or you type the address by hand. Which device reads and which one controls does not depend on who shows the code, but on the button pressed in Start. Both must be on the same Wi‑Fi network, or one of them must be a hotspot.
  • After connecting, open Start on the device whose text you want to play. Show on … plays the text selected here on the other device, and this device controls it. Full screen and In a window play the text only here. The names follow the real type of the other device – computer, phone or tablet: the phone says Show on the computer, and the computer says Show on the phone. Until the type is known, the word “device” is used.
  • Texts are moved between the devices with the Exchange button in the Library panel (get and send). The button is gray when there is no connection; without one the button opens the connection screen and the Text actions menu (send).
  • When the device shows its text on the computer, the computer's main window locks (“Controlled over the network”) and shows the text read-only with its progress. Everything is controlled from the device. The Close button brings the editor back on the computer, and the device gets a message and leaves Network mode.
  • When you press Show on the device on the computer, the roles are reversed: the device reads full screen and the computer is in control, as with a second display.
  • While the computer is reading the device’s text, the device shows a live preview with large buttons: play and pause, full screen, close, speed and size. Bookmarks and Editor open a panel in the top half, and Settings opens a window.
  • Full screen on the device shows the text with the same aspect ratio and orientation as the reading screen, for example 16:9 landscape. Spare space at the edges stays empty.
  • At any moment the text is controlled by one device, so the two texts never get out of step.
  • The address contains a secret code. The connection does not go to the internet: the devices communicate directly. Windows may ask for network permission the first time.

Clicker and presenter

Turn it on in Settings → Presenter clicker control. With the clicker on, F5 in the editor starts full-screen reading.

  • F5, Enter or Play/Pause are the start and pause button. PgDn or next track is “forward”, and PgUp or previous track is “back”.
  • There are four modes: Speed, Bookmarks, Library and Size. The current one is shown on screen. Double-pressing the start button switches between “Speed” and “Size”. Holding it opens “Bookmarks”, the next hold opens “Library”, and the third closes the panel and returns to “Speed”.
  • In “Speed” mode forward and back change the speed in steps of 5 (1 with Shift), and in “Size” the size by 1. In “Bookmarks” and “Library” they switch between “Bookmarks” and “Library”, the up and down arrows select a row, a single press of the start button picks it, and a double press closes the panel without picking.
  • The “Bookmarks” and “Library” modes are available only if there are bookmarks or texts.
  • Without the clicker, PgUp and PgDn move the text one page back and forward.

Settings

  • Speed (1–100) and “Swap up and down”.
  • Font: font, size (20–240), line spacing (1–2.4), paragraph spacing (0–1.5), text width (30–100%), text and background colors, and ready-made “Aa” combinations. The Add font button adds your own fonts from a file (.ttf, .otf, .woff, .woff2), for example for Arabic, Greek, Chinese or another language. They stay on this device and are also used in the second window; on other devices they are added separately. The same button removes them.
  • Encoding of .txt files: UTF-8 files are read automatically. For older files (for example windows-1253 for Greek or windows-1256 for Arabic) choose the encoding in Settings and open the file again.
  • Mirror: horizontal and vertical.
  • Progress bar: shows the bar in the controls.
  • Reading marker: on or off, position (10–90), height (40–800), dimming (0–90) and color.
  • Appearance: light or dark theme, accent color and interface background, and “Reset colors”. Interface colors do not affect the text in the teleprompter; changing the theme resets them.
  • Start: start mode — ask every time, full screen or in a window.
  • Language: BG or EN. This changes the interface language, not your texts.
  • Spell check in the editor.
  • Presenter clicker control.
  • Start with Windows (Windows app only): starts TPrompt minimized when you sign in to Windows.

Good to know

  • If single keys such as T, B or S do not respond, click outside the text. While the cursor is in the editor they type letters.
  • Data is kept on this device. If you clear the program's data or uninstall it, it is lost, so make copies with Export.
  • If full screen does not turn on, try F11.
  • On a narrow screen, Library, Editor and Bookmarks are chosen from the buttons at the top, and Settings opens in a window.
